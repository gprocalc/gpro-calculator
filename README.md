# GPRO Calculator — free setup, fuel & tyre strategy calculator for Grand Prix Racing Online

**Website: https://gprocalc.com**

GPRO Calculator is an **unofficial, fan-made web tool** for players of the browser game **Grand Prix Racing Online (GPRO)**. It is **not the game** and is **not affiliated with, endorsed by or connected to GPRO or its developers**: it was built by passionate GPRO managers for other managers.

This repository is the public presentation page of the tool. The application runs online at [gprocalc.com](https://gprocalc.com); no source code is published here.

## What it does

Connect your **read-only GPRO API token** and the calculator reads your team, driver and car data to give you, race after race:

- **GPRO setup calculator** — car setup for Q1, Q2 and the race (front wing, rear wing, engine, brakes, gearbox, suspension), with the alternative setup for the opposite weather. → https://gprocalc.com/setup-calculator
- **GPRO fuel calculator** — fuel to load at the start and at every pit stop, with the safety margin you choose. → https://gprocalc.com/fuel-calculator
- **GPRO tyre strategy** — tyre compound, number of pit stops and laps per stint for all five compounds. → https://gprocalc.com/tyre-strategy
- **Pit stop calculator** and wing split reference. → https://gprocalc.com/pit-stop-calculator
- **Rain strategy** for mixed-weather races (dry and wet phases). → https://gprocalc.com/rain-strategy
- **Qualifying setup** for Q1 and Q2. → https://gprocalc.com/qualifying-setup
- **Practice laps**: record your test laps and get the next setup to try. → https://gprocalc.com/practice-laps
- **Post-race analysis**: report card comparing the plan with what really happened. → https://gprocalc.com/post-race-analysis
- **Parts wear** and **race risks** guides. → https://gprocalc.com/parts-wear · https://gprocalc.com/race-risks
- **All 64 GPRO tracks** with track data. → https://gprocalc.com/tracks
- Driver analysis, car analysis, sponsor advisor, driver market, rivals.
